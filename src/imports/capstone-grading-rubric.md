Based on the **STI Capstone Project Guideline** and the **Course Syllabus**, here are the detailed rubrics for the panelists and the final total grade.

### **I. Panelist Grading Rubric (Defense Activity Grade)**
The defense accounts for **60% of the total grade**. Panelists evaluate the group as a whole and each student individually using a **0 to 4 point scale**.

#### **A. Group Grade (60% of the Defense Grade)**
| Criteria Component | Description |
| :--- | :--- |
| **Capstone Project Manuscript** | Evaluation of the research paper's quality, formatting, and content. |
| **Final Multimedia Output** | Evaluation of the actual product (film, exhibit, etc.) and its relevance. |
| **Oral Defense Presentation** | Evaluation of the logical flow and effective use of visual aids. |

#### **B. Individual Grade (40% of the Defense Grade)**
| Criteria Component | Description |
| :--- | :--- |
| **Communication Skills** | Clarity and confidence in answering panel questions. |
| **Work Organization** | Preparedness and logical flow of the individual's portion. |
| **Effectiveness** | How well the student defends their specific contribution. |

---

### **II. Total Grade Rubric (Final Term Grade)**
The final grade for the term is a weighted combination of scores from the defense panel, the project adviser, and the project coordinator.

| Component | Weight | Sub-Criteria & Weights |
| :--- | :--- | :--- |
| **Defense Activity Grade** | **60%** | Group Grade (60%) + Individual Grade (40%) |
| **Adviser’s Grade** | **30%** | Attendance to submissions (15%) + Participation (25%) + Project involvement (60%) |
| **Coordinator’s Grade** | **10%** | Task performance (20%) + Submission of requirements (80%) |

**Note:** Failure in the defense or re-defense automatically results in a **failing grade (5.00)** for the entire course.

---

### **III. Performance Rating Scale**
Panelists use this scale to assign points for the criteria mentioned in the Defense Activity Grade:

| Score | Rating | Description |
| :--- | :--- | :--- |
| **4** | **Excellent** | Consistently high quality; exceeds all standards. |
| **3** | **Exceeds Expectations** | Strong performance above minimum requirements. |
| **2** | **Meets Minimum** | Satisfactory work that meets basic standards. |
| **1** | **Meets Sometimes** | Inconsistent quality or minor missing elements. |
| **0** | **Does Not Meet** | Significant deficiencies or missing major parts. |

---

### **IV. Grade Evaluation and Verdict Table**
The weighted points are totaled into a **Raw Score (%)**, which determines the official verdict and numerical grade:

| Raw Score (%) | Verdict | Numerical Grade |
| :--- | :--- | :---: |
| **98 – 100** | **Pass** | **1.00** |
| **89 – 97** | **Pass with Minor Revisions** | **1.25 – 1.75** |
| **75 – 88** | **Pass with Major Revisions / Re-demonstration** | **2.00 – 3.00** |
| **Below 75** | **Failed (or Re-defense required)** | **5.00** |

*Special Note for Re-defense:* After a re-defense, the student’s grade is restricted to either **Passed (3.00)** or **Failed (5.00)**.
